# 安装说明（macOS 提示「已损坏」必看）

## 为什么会提示「已损坏」？

这不是安装包真的坏了。macOS 对所有从网上下载的未签名 App 会自动加上「隔离标记」，并在新版系统上直接提示「已损坏，应该移到废纸篓」。**文件本身完全正常**。

## 解决方法（任选其一）

### 方法一：终端命令（最靠谱）

1. 把 `BabyDesktopPet.app` 拖到「应用程序」文件夹（或任意位置）
2. 打开「终端」App（启动台 → 其它 → 终端，或 Spotlight 搜「终端」）
3. 复制粘贴下面这行命令后回车（注意 `-cr` 后面有个空格）：

```bash
xattr -cr /Applications/BabyDesktopPet.app
```

> 如果没放到「应用程序」，把路径换成你放的位置。最快的办法是先输入 `xattr -cr `（末尾带空格），再把 App 图标拖进终端窗口，路径会自动填好，然后回车。

4. 再双击 App，就能正常打开了。

### 方法二：右键打开

在 Finder 里**右键点击** BabyDesktopPet.app → 选「打开」→ 弹窗里再点「打开」。
（部分 macOS 版本对「已损坏」提示无效，请用方法一。）

### 方法三：系统设置里允许

打开「系统设置 → 隐私与安全性」，往下滚动找到「已阻止使用 BabyDesktopPet」，点「仍要打开」。

---

## 常规使用

- 解压后双击运行即可
- 首次运行若被拦截，按上面方法处理
- 之后不会再被拦截
- 右键宝宝图标可看到菜单（切换动作、变大变小、躲起来、举相框等）
